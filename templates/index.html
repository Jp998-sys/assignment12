FastAPI User and Calculation Routes Project

This project includes user registration and login, along with full calculation BREAD routes using FastAPI, SQLAlchemy, Pydantic, PostgreSQL, Docker, and GitHub Actions.

Available API Features:

  • User registration
  • User login
  • Browse calculations
  • Read a calculation
  • Add a calculation
  • Update a calculation
  • Delete a calculation
