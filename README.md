# Module 12 Assignment
# FastAPI User and Calculation Routes Project

## Overview
This project builds on the earlier modules by adding user registration and login routes, along with full calculation BREAD routes in FastAPI. It uses SQLAlchemy models, Pydantic schemas, PostgreSQL, pytest integration testing, Docker, and GitHub Actions CI/CD.

## Features
- User registration endpoint
- User login endpoint with password verification
- Calculation browse route
- Calculation read route
- Calculation add route
- Calculation update route
- Calculation delete route
- SQLAlchemy models for users and calculations
- Pydantic validation for request and response data
- Integration tests for user and calculation routes
- Docker setup for local development
- GitHub Actions for automated testing and deployment
- Docker Hub image deployment
